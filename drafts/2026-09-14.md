## LinkedIn

**Hook**
This week I built three agents to watch my inbox and deadlines. The first version texted me about a routine circular marked URGENT.

**Body**
I kept missing scholarship and hackathon deadlines because finding them meant remembering to check.

So I built three agents on top of my own laptop. One watches college mail over read only IMAP. One tracks every competition, internship, hackathon and scholarship as a deadline with a reminder ladder: 7, 3, 1, 0 days out. One watches Classroom and nudges at 72, 24, 12 and 3 hours before a submission is due.

The first version was too eager. A college domain got weighted the same as a named sender, so every routine circular scored high enough to buzz my phone marked URGENT. My library book reminder was getting the same treatment as my scholarship deadlines.

Fixed it so an alert now needs an actual subject category or a named sender before it interrupts me, not just a familiar looking address. 2299 tests later it only speaks up when something is actually due.

## Newsletter

**Subject**
My deadline agent flagged a library email as urgent

**Body**
This week I finished three agents that watch my college inbox, my deadlines and Google Classroom, then spent the rest of the week finding what breaks when someone other than me relies on them.

The deadline agent runs a reminder ladder: 7, 3, 1 and 0 days out for anything I mark INTERESTED, whether that's a hackathon, an internship or a scholarship. Classroom nudges at 72, 24, 12 and 3 hours before something is due. The inbox agent is the one that misbehaved first: it scored my college domain the same as a named sender, so a routine circular about the library scored high enough to buzz my phone as URGENT. An alert now needs a real subject category or a named sender before it can interrupt me, not just a familiar address.

The bug that actually worried me was different. Every approval in the system was being recorded against a hardcoded name, mine, so if a friend used the app and approved something, the record would say I had, which is a quiet falsehood in the one log that exists to be true. It now reads who is actually running it instead of assuming.

None of this runs unless a browser tab is open, which I wrote down plainly rather than rounding up: close the laptop and nothing is checking your mail yet. That's next.

**Close**
If you've built something for yourself first, what's the bug that only showed up once someone else touched it?
