## LinkedIn

**Hook**
My AI agent used to sign every post as me. Even when a friend was the one who asked it to write.

**Body**
No error. No warning. Press the button as anybody else and it drafts a post composed as a 21-year-old marketer named Jasmehr, about his week.

I only found it because I imagined a friend pressing it.

Three things stood between this thing and handing it to a friend or a parent. It refused to even open without a config file, so the screen built so nobody would have to touch a text editor was unreachable until you had already opened one. Every prompt named me, hardcoded. And two panels each kept their own clock, so a card could say 5 days left while the reminder believed 4.

It now opens with nothing configured and says what is missing. The brief carries a slot filled from whoever is running it, and says "the person using this" when nobody has said who they are. Inventing a default name felt safer and was worse: a wrong name in a prompt is a post signed by a stranger.

2,299 tests pass on it now. None of them would have caught this, because every one of them was written by the person who already knew who "you" meant.

## Newsletter

**Subject**
The bug where my app signed posts as me

**Body**
Every prompt in Agent OS, the system that reads my commits and drafts these posts, was hardcoded to one name. Press "write my drafts" as anybody else and it still writes as a 21-year-old marketer called Jasmehr, in his voice, about his week. Nothing throws an error. The output is just quietly about the wrong person.

I only caught it by imagining a friend running it. Before I could even fix that, I found the app would not open without a config file in the first place, which meant the screen I had built specifically so nobody would have to hand-edit a text file was unreachable until you had already done the thing it existed to prevent.

The fix was a single slot in every brief, filled from whoever is running the app, that falls back to "the person using this" rather than guessing a name. A test now fails if a brief hardcodes a pronoun or a name again. Separately, I found two panels in the same app were each keeping their own clock instead of sharing one, so a deadline card could say 5 days left while the reminder ladder believed 4, both correct from where they stood.

2,299 tests pass on the app right now. None of them caught the naming bug, because every test was written by someone who already knew who "you" meant.
